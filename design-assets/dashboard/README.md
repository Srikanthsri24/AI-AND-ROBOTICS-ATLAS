# Dashboard illustration assets

The original dashboard used small CSS crops from the supplied reference image. This directory records the replacement standalone artwork, generated with the built-in image generation tool, plus the exact prompts. Original outputs are retained here; web delivery variants live in `public/images/dashboard/`.

These are conceptual educational illustrations. They are not manufacturer product photographs, exact CAD, pinout references or evidence of hardware specifications. No generated UI labels or brand marks are used.

Web delivery uses separately generated images, proportional sizing and responsive image sources. Category images use a safe central composition for the existing wide card format. The dashboard layout and navigation remain unchanged.
