# Evolution of Technology artwork

Generated with the built-in image generation tool for the redesigned static Evolution screen.

- Original new images: this directory (`*.png`).
- Exact generation prompts: [prompts.json](prompts.json).
- Original tool output locations: [manifest.json](manifest.json).
- Responsive public images: `../../public/images/evolution/`.
- Reused high-resolution milestone artwork: `../../public/images/dashboard/`.

Fifteen new illustrations include a panoramic hero, simple machines, an early textile mill, electric dynamo, historical production line, tubes/transistors, machine learning, integrated circuit, PLC cabinet, microprocessor, mobile devices, cloud computing, generative AI, multimodal AI and agent tool use. Originals are 1536 × 1024 for milestone illustrations; the hero is 2172 × 724. JPEG delivery variants preserve proportions and use high-quality encoding.

The images are interpretive educational illustrations and historical reconstructions. They are not authenticated artifact photographs, exact hardware schematics, or verified depictions of hypothetical future capabilities.
