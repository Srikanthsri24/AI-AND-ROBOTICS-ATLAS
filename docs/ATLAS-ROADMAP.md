# Atlas delivery goals

1. Complete the 2D catalogue first: 40 component, 30 controller/computer, 50 sensor/IoT, 60 robot/mechanism and 60 anatomy families. Include the user's named variants, family-specific explanations, why/how guidance, use cases, selection criteria, limitations, relevant high-resolution group artwork and meaningful interactive 2D functional diagrams. Verify navigation, search, saves and mobile layouts.
2. After 2D coverage passes validation, implement interactive 3D across the same catalogue. Use realistic materials and appropriate representative geometry, and distinguish illustrative family models from exact engineering/product models. Validate loading, controls, fallback and performance.
3. After both catalogue phases, redesign Circuit & Code Laboratory, Project Builder, AI Robotics and Learning & Assessment around the expanded learning content. Keep experiments honest, testable and frontend-only.

All work stays local, static and English-only.
